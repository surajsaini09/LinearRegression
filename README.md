## 📈 Linear Regression

Linear Regression attempts to model the relationship between input features and a continuous target.

For a simple linear regression problem:

```text
y = mx + b
```

Where:

* `y` → predicted value
* `x` → input feature
* `m` → slope
* `b` → intercept

The model learns the parameters that provide the best fit to the training data.

---

## 📊 Evaluation Metrics

The model is evaluated using common regression metrics:

| Metric       | Purpose                                                             |
| ------------ | ------------------------------------------------------------------- |
| **MAE**      | Measures average absolute error                                     |
| **MSE**      | Measures average squared error                                      |
| **RMSE**     | Measures typical prediction error in target units                   |
| **R² Score** | Measures how much variation in the target is explained by the model |
